# 회의실 예약 매뉴얼 (샘플)

## 1. 예약 방법
회의실은 Google 캘린더를 통해 예약합니다.

1. Google 캘린더를 엽니다.
2. 원하는 시간대를 선택합니다.
3. "회의실" 추가에서 예약할 회의실을 선택합니다.
4. 저장하면 예약이 완료됩니다.

## 2. 회의실 목록
| 회의실 | 위치 | 수용 인원 | 비고 |
|--------|------|-----------|------|
| 대회의실 | 3층 | 20명 | 화상회의 장비 |
| 중회의실 | 2층 | 8명 | 화이트보드 |
| 소회의실 A | 2층 | 4명 | - |
| 소회의실 B | 2층 | 4명 | - |

## 3. 이용 규칙
- 예약 시간을 초과하지 마세요.
- 사용 후 정리정돈은 필수입니다.
- 노쇼가 3회 누적되면 예약 권한이 제한됩니다.

## 4. 취소
회의가 취소되면 캘린더에서 일정을 삭제해 다른 사람이 사용할 수 있게 합니다.

> 본 문서는 인덱싱 테스트용 가상 샘플입니다.

# ADR 0004 — 임베딩 모델 후보 선정 (Embedding Model Selection)

- 상태(Status): Provisional (후보 선정 완료, 13단계 비교 실험 후 확정)
- 날짜(Date): 2026-05-25
- 작성자(Author): vittroi384
- 관련 단계(Stage): Phase 1 / 3단계 (하이브리드 데이터소스 + 청킹/임베딩 ADR)
- 관련 ADR: ADR 0003 (청킹 전략), 22단계 pgvector 마이그레이션 검토와 연결

## 맥락 (Context)

RAG 검색 품질의 핵심은 임베딩 모델이다. 사내 문서가 한국어 중심이므로
한국어 의미 검색 성능이 중요하다. 1차 운영은 Vertex AI Search 통합 환경에서
시작하지만, 향후 자체 호스팅/벡터DB(pgvector) 전환 가능성을 열어둬야 한다.

제약 및 환경:
- 문서/쿼리 모두 한국어 중심.
- 1차 운영은 Vertex AI Search(매니지드) 기본 임베딩에 의존.
- 솔로 개발자 — 자체 호스팅 모델은 운영 부담(GPU/서빙 인프라)이 크다.
- 비용 가드레일 월 ₩50,000. 자체 호스팅은 상시 컴퓨팅 비용이 발생.

## 결정 (Decision)

비교 후보 3종을 선정한다:

1. **text-embedding-004** (Google) — 1차 운영 채택.
   Vertex AI Search에 통합되어 별도 서빙 불필요, 매니지드.
2. **multilingual-e5-large** (오픈소스) — 비교 후보. 다국어 강점, 자체 호스팅 필요.
3. **bge-m3** (BAAI, 오픈소스) — 비교 후보. 한국어 포함 다국어 특화, 자체 호스팅 필요.

1차 운영은 `text-embedding-004`로 시작하고, **13단계에서 한국어 골든셋으로
3종을 정량 비교**하여 최종 모델을 확정한다.

> 검색 필요(확정 보류): 2026년 5월 시점 Vertex AI의 기본 권장 임베딩 모델이
> `text-embedding-004`인지, 후속 모델(gemini-embedding 계열 등)로 갱신되었는지는
> 13단계 실험 직전 공식 문서로 재확인한다. 본 ADR은 후보 선정까지만 확정한다.

## 비교 메트릭 (13단계 측정)

- **Recall@5** — 정답 문서가 상위 5개 안에 포함되는 비율.
- **MRR** (Mean Reciprocal Rank) — 정답의 평균 역순위.
- **응답 시간 P95** — 검색 지연 95퍼센타일.
- **운영 비용** — 매니지드(쿼리당 과금) vs 자체 호스팅(상시 컴퓨팅) 환산.

## 근거 (Rationale)

- **매니지드 우선**: 솔로 개발자 환경에서 자체 호스팅 임베딩 서빙은 운영/비용 부담이
  크다. 1차는 매니지드로 빠르게 가동.
- **후보 보존**: e5-large, bge-m3는 한국어 성능 잠재력이 있어 비교 가치가 있으나,
  근거 없이 자체 호스팅을 먼저 도입하지 않는다(측정 후 결정).
- **확장성**: 22단계 pgvector 전환 시 자체 임베딩이 필요해지므로, 그 시점 비교
  데이터를 13단계에 미리 확보한다.

## 결과 (Consequences)

긍정적:
- 3단계~12단계 운영을 매니지드 임베딩으로 단순하게 유지.
- 13단계에 한국어 임베딩 비교 실험이라는 명확한 포트폴리오/블로그 자산 확보(블로그 2번).

부정적/리스크:
- 매니지드 기본 임베딩의 한국어 성능이 충분한지 13단계 전까지는 정량 확인 불가.
- 자체 호스팅 후보(e5, bge-m3) 비교 시 GPU/서빙 환경 구성 비용·시간 발생(13단계 한정).

## 재검토 트리거 (Revisit Triggers)

- 13단계 골든셋에서 매니지드 임베딩의 Recall@5/MRR 목표 미달.
- 22단계 pgvector 마이그레이션 결정 시 자체 임베딩 모델 확정 필요.
- Vertex 기본 임베딩 모델이 후속 버전으로 교체되어 재평가가 필요한 경우.
